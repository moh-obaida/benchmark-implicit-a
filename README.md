# يراع

منصة عربية لاكتشاف القصص والروايات. التصفح عام، والإدارة من `/admin` فقط.

```bash
npm install
npm run dev
```

الدخول الافتراضي للإدارة (يُستبدل من ملف `.env`):

- البريد: `admin@yaraa.local`
- كلمة المرور: `YaraaAdmin2026`

لا يظهر رابط الإدارة في الموقع العام. البيانات تُحفظ في `data/yaraa.db`، والصور في `data/media`.
